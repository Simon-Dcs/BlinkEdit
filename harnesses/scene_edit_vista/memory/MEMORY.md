# Grounded editing experience

Observe current public facts before each new instruction. Missing factual context
can cause needless clarification even when explicit support relationships resolve
the request. Use current support IDs and rooms; bounds and positions provide
physical context but are not a substitute for host geometry validation.

Recover historical insertion references through a unique stable identity match.
External editing can change a link name, room or support without changing identity.
Keep historical placement separate from current physical state. An absent stable
identity stays absent; similar assets, reused names and nearby objects are not
identity evidence. Duplicate identities require clarification. Never create
confirmed history from attempted edits or tool-result callbacks.

Refresh observations on every request. A successful empty observation is valid;
an observation error is not an empty scene. Supplied current request facts may
recover observation availability. Never use stale cached facts as current truth.

Preserve the parsed plan. Existing evidence supports better grounding, not target
substitution, asset changes or placement-order heuristics. Retain one full-budget
placement attempt. A failed execution with no error, despite passing public
geometry checks, does not identify a retryable mechanism. Do not invent a failure
cause or spend additional attempts without evidence and advance budget allocation.
